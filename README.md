# Reliance Industries Limited (RIL) - Financial Model & Valuation Dashboard

## Project Overview
This project features a dynamic, fully integrated **Three-Statement Financial Model** and an **Executive Valuation Dashboard** for Reliance Industries Limited (RIL). It combines data extraction, detailed financial forecasting, and interactive data visualization to estimate the company's intrinsic value and equity upside.

## Tools & Technologies Used
* **Microsoft Excel:** Advanced financial modeling, forecasting, and formula architecture.
* **SQL:** Querying and structuring historical financial data from databases.
* **Power BI:** Designing executive-level interactive charts and valuation metrics.

## Key Features & Methodology
* **Integrated 3-Statement Model:** Built a dynamic, fully linked model (Income Statement, Balance Sheet, and Cash Flow) to forecast 3 years of future corporate performance.
* **Corporate Valuation:** Conducted a Discounted Cash Flow (DCF) valuation and calculated the Weighted Average Cost of Capital (WACC) to estimate RIL's intrinsic value.
* **Executive Dashboard:** Designed a high-impact Power BI dashboard to visualize revenue trends, EBITDA margins, valuation multiples, and capital structure changes.
